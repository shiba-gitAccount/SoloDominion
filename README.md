# Dominion Single-Player Replica in Unity

Unityでのゲーム開発、オブジェクト指向設計、およびデータ構造の管理を学ぶために作成した、大人気ボードゲーム『ドミニオン』の一人プレイ用再現プロジェクトです。複雑なカード効果の自動処理、非同期の進行制御、データと表示の分離設計を自前で実装しています。

## 🎯 開発目的・概要
- **目的**: Unityにおける複雑なゲームロジックの構築、非同期処理、データ駆動型のオブジェクト設計、および状態遷移管理の習得。
- **内容**: ドミニオンの基本ルール（公式サプライ準拠）をベースに、山札・手札・捨て札の管理から、ターン進行、カード効果の処理までを完全デジタル化。
- **ビジュアル**: 各種カードのイラストには親しみやすい「いらすとや」の画像を採用し、直感的にカードの種類を識別できるように配置しています。

---

## 🕹️ ゲーム進行フローと自動化の切り分け
プレイヤーの選択の自由度を残しつつ、面倒な計算やクリーンアップ処理をシステムが全自動で行う、ストレスフリーな進行環境を構築しました。

### 👤 プレイヤーが操作する部分
1. **ゲーム開始時**: タイトル画面でゲームモード（公式サプライ）を選択してスタート。
2. **アクションフェイズ**: 手札のアクションカードを使用するか、進めるために「フェイズ終了ボタン」を押す。
3. **購入フェイズ**: 購入したいカードを選択する（所持金が足りないカードは購入できないよう自動制御）。購入数が残っている状態での「フェイズ終了ボタン」による手動終了。

### 🤖 システムが全自動処理する部分
- 起動時の初期手札5枚ドロー。
- 購入フェイズ移行時の**財宝カードの自動一括使用**と使用可能金額の計算。
- 購入回数消費時の、購入フェイズ自動終了処理。
- ターン終了時の**クリーンアップ処理**（手札・プレイエリアのカードを捨て札に送り、山札から新たに5枚ドロー、山札不足時の自動シャッフル）。

## 🏗️ データの構造と設計（M-Vアーキテクチャの意識）
カードの情報管理において、**データ（不変）**と**状態・表示（可変）**を完全に切り分ける堅牢な設計を行いました。

- **`CardData`（不変のデータ）**: 
  ScriptableObject等を用いて、カード名、分類（アクション/財宝/勝利点など）、カード画像、サプライ用画像、コスト、およびカード効果の定義を保持。
- **`CardView`（状態と表示の制御）**: 
  実際にゲーム画面に登場するオブジェクト。内部に `CardData` を参照として持ちつつ、そのカードが現在どこにあるか（手札、捨て札、プレイエリア、廃棄場など）の**場所の情報**や、実際の描画（RectTransformの制御など）を管理。

この分離により、カードの移動や状態変化（List間の移動）をバグなく安全に行うことができます。

## 🔥 最も苦労した点と技術的解決策

### 1. 「玉座の間」に代表される、コルーチンによる非同期・待機処理の制御
本作の開発で最も困難だったのは、**「選択したアクションカードの効果を2回発動する」という『玉座の間』の効果実装**です。

#### 🔹 発生した問題
当初、カード効果を単純な関数呼び出しで実装していたため、1回目のカード効果（例：カードをめくって選ぶ）が**終了する前に**、2回目の効果や次のドロー処理が重なって暴走してしまう問題が発生しました。特に『前駆者』や『衛兵』のように「ドロー効果」と「カード選択効果」が複合しているカードを玉座の間で使用すると、プレイヤーが画面上でカードを選択している最中に次のドローや処理が実行され、手札や山札のデータ整合性が崩れるバグが多発しました。

#### 💡 解決策（Unityコルーチンの活用）
すべてのカード効果の実行プロセスを、Unityの **Coroutine（コルーチン）** を用いた待機可能な非同期処理へと刷新しました。
カード効果の完了（プレイヤーの選択やドローアニメーションの完了）を待ってから次の処理ステップへ進むように制御。これにより、どれだけ複雑に効果がネスト（階層化）されても、データが破壊されずに順番通り処理される仕組みを確立しました。

### 2. 変数による厳密なフェイズ遷移管理
ゲームのフェイズ進行は `currentPhase` 変数を用いて一元管理しています。
「カードを使用した時」「ボタンを押した時」など、あらゆるタイミングで現在の `currentPhase` を厳格にチェックし、フェイズの不正なスキップや、購入フェイズ中にアクションカードが使えてしまうといったデジタル特有の不正挙動を完全にシャットアウトしました。
